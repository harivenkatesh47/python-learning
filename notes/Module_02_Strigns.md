## Module 02: Strings in Python - Core Concepts

### 1. String Extraction & Formatting
*   **Slicing in strings:** Using index positions to extract specific substrings or reverse text (e.g., `[start:stop:step]`)[cite: 1, 2, 11].
*   **f-strings:** Prefixing a string with `f` to dynamically inject variables or expressions directly into text using curly braces `{}`[cite: 1, 2, 11].
*   **Escape sequences:** Special character combinations (like `\n` for a new line, `\t` for tab, or `\"` for literal quotes) used to format console layout[cite: 1, 2, 11].

### 2. String Operations & Methods
*   **Membership:** Using the `in` operator to verify if a specific substring exists inside another string[cite: 1, 2, 11].
*   **Cleaning:** Using the `.strip()` method to remove accidental or unwanted leading and trailing whitespace from a string[cite: 1, 2, 11].
*   **Replacing:** Using the `.replace()` method to dynamically overwrite specific target words or characters within a string[cite: 1, 2, 11].
*   **Counting:** Using the `.count()` method to determine the exact frequency of a specific substring's occurrence[cite: 1, 2, 11].
*   **Casing Transformations:** Standardizing text size using methods like `.upper()`, `.lower()`, and `.title()`[cite: 1, 2, 11].
*   **Boundary Checks:** Evaluating conditions using `.startswith()` and `.endswith()` to check if a string begins or concludes with a specific pattern[cite: 1, 2, 11].
