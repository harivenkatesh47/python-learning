# Module 01: Python Basics - Revision Notes

## 1. Core Elements
* **Literals:** Raw data values written directly into code (e.g., `10`, `"Hello"`).
* **Variables:** Named memory containers used to store data.
* **Keywords:** Reserved words (e.g., `if`, `def`, `True`) with built-in meanings. Do not use as variable names.

## 2. Primitive Datatypes & Conversion
* **Types:** Integers (`int`), Decimals (`float`), Text (`str`), and Booleans (`bool`).
* **Type Casting:** Explicitly converting data. 
  * *Example:* `float(input())` converts string input to a decimal number.
  * *Boolean casting:* `bool(0)` is `False`, `bool(1)` is `True`.

## 3. Operators & Precedence
* **Arithmetic:** `+` (add), `-` (subtract), `*` (multiply), `/` (divide), `//` (floor division), `%` (modulus), `**` (exponent).
* **Comparison:** `==` (equal), `!=` (not equal), `>`, `<`, `>=`, `<=`. Return `True` or `False`.
* **Logical:** `and`, `or`, `not`.
* **Precedence:** Python evaluates math following strict associativity rules (similar to PEMDAS).

## 4. Input & Output
* `print()`: Displays output to the console.
* `input()`: Pauses execution to accept string input from the user.
