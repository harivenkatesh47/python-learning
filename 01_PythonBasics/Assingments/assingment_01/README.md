# Assignment 1: Basic Python Concepts

## Learning Objectives
Demonstrate mastery of user input, type casting, basic arithmetic operations, error handling, and string manipulation.

## Task 1: Basic Mathematical Operations
Write a script that:
1. Takes two numeric inputs from the user.
2. Performs addition, subtraction, and multiplication.
3. Performs division, but includes logic to handle division by zero.
4. Uses a `try-except ValueError` block to catch invalid text input.

## Task 2: Personalized Greeting
Write a script that:
1. Takes the user's first name and last name as separate inputs.
2. Uses `.strip()` to remove accidental whitespace.
3. Uses string formatting (f-strings) to print a dynamic greeting containing their full name.
